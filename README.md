# NOD News

Static marketing site at [nodnews.com](https://nodnews.com). Signal feed / newsroom for Dan Cruz's NOD brand. Single-page, GitHub Pages, no build step.

## Stack
- Single `index.html` (no bundler, no framework)
- Vanilla JS + CSS (Inter / Cinzel / Anton via Google Fonts)
- Mobile-first responsive

## Editing
Edit `index.html` directly. Commit on a feature branch, push, open PR. GitHub Pages auto-deploys from `main`.

## Cross-promo ads
The MixMatch cross-promo mini-ad at `mixmatchminiad` is shared across NOD sites (nodnews, dancruzhomes, fatcatpm). When updating, edit each site's section inline OR factor into a shared asset (not done yet — premature factoring).
